What RouterForge does

RouterForge is a static, browser-based set of helpers for drafting RouterOS 7 configuration scripts. The service configurator covers PPPoE, Hotspot, static-IP MAC RADIUS access, WAN settings, and related NAT and RADIUS settings. Separate tools generate multi-WAN routing and WireGuard scripts.

The tools validate values in the browser and create an .rsc export for you to inspect, copy, or download. RouterForge does not connect to your router or apply changes automatically.

Use with care

Network configuration is environment-specific. Review interface names, routes, addressing, credentials, firewall order, and existing configuration before import. Keep a tested backup and a recovery path. RouterForge is a drafting aid, not a substitute for change control or network administration.

The educational guide links to the relevant official RouterOS documentation; verify commands against the RouterOS version running on your device.

PRIVACY POLICY

What this site does
with your data today.

Current operation

RouterForge is a static website. Its configuration tools run in your browser. The values you enter, including credentials and generated scripts, are used by your browser to create output and are not sent by these tools to a RouterForge server.

This version of the website does not include a contact form, account system, analytics tag, advertising tag, tracking pixel, or first-party cookie banner. It does not intentionally set cookies or use browser storage for tool inputs.

Downloads and external links

When you download a generated script, the file is created by your browser. Links to third-party sites, including MikroTik documentation, open those sites under their own privacy practices; RouterForge does not control them.

Your choices and changes

Because this version does not receive configuration inputs or operate user accounts, there is no server-held configuration data to access, correct, or delete. If the site’s collection practices change, this policy will be revised and a real contact method should be added for privacy requests.
